# Posters Wallah — Website

## Run
Open `index.html` in VS Code and use Live Server, or open it directly in a browser.

## Instagram
The site uses the Instagram DM link for `@posters_wallah`:
https://ig.me/m/posters_wallah

The cart creates an order message, copies it to the clipboard, and opens Instagram. Instagram does not allow an ordinary website to silently send a DM from the visitor's account, so the visitor still taps Send.

## Images
Your two supplied room photos are included in `assets/`.
The catalogue uses remote Unsplash images so the ZIP stays small. The referenced Unsplash pages identify the images as free to use under the Unsplash License.

## Important
Replace the remote image URLs with your own poster product photos before taking real customer orders. Product photos should represent the exact designs you sell.
